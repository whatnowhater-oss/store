How a request flows through Flask
1. The WSGI server calls Flask.__call__, which calls wsgi_app (app.py:1627).
2. wsgi_app builds a context and pushes it, so request, session, g work.
3. full_dispatch_request runs every before_request hook. If one returns
   a value, that becomes the response and the view never runs.
4. dispatch_request finds the view for the matched URL rule and calls it.
